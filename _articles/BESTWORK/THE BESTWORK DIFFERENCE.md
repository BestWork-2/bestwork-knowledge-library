What is BestWork DATA & How Is It Different?

BestWork DATA is a data application that is replacing traditional

assessments. It is a disruptive innovation. Explaining the difference

between BestWork DATA and traditional assessments is difficult. It is the

same as explaining the difference between an IPhone 6 and the early flip

phones. They both make calls, but after that, the comparison becomes

meaningless. Traditional assessments and BestWork DATA both use

psychometric instruments, but after that, the comparison is less relevant.

Clayton Christensen addressed this in The Innovator’s Dilemma, explaining

that it is not possible to understand a disruptive innovation by comparing it

to what it is displacing. The disruptor creates an entirely new value system.

Some of the features of this new value system are described below: Talent Acquisition The DATA is an objective measurement of the hard-wired personality strengths and cognitive abilities of an individual. With this DATA, it is possible to describe how that individual will perform any job element that is dependent upon thinking, learning or behaving. While certain knowledge and skills also play a role in job performance, DATA reveals the foundation upon which the knowledge and skills rely. For example, basketball skills and knowledge produce dramatically different results for a player 7 feet tall than for a player 5 feet tall.

Traditional assessments create a benchmark or profile and

compare candidates to that profile, producing a percentage

match. Above 70% is generally acceptable; above 80% is

desirable; and above 90% is outstanding. This methodology is

effective in identifying gross mismatches to the profile. It is

significantly less effective in recognizing problems with

candidates who are fairly good matches, and even 90+%

matches can lack critical job strengths in that missing 10% or so.

DATA first screens out candidates who do not have the strengths

or abilities that are critical to performing that particular job. The

candidate is not evaluated holistically, but specifically with regard

•Can this candidate persuade prospects to buy? Yes or No?

•Can they handle complex solution sales? Yes or No?

•Can this programmer write consistent code? Yes or No?

This is done with simple reports, designed for this specific decision

point. It can even be done automatically in the case of a high

volume of candidates. Once this screening is completed, any

candidate selected from the remaining pool can do the job.

DATA now outputs a different type of report for selection, with a

comprehensive description of how each job behavior is performed

by the candidate. These are in both chart form and with

descriptive text that is easily understood by anyone without the

need for special training. These reports are written in the

terminology used by the clients and for each job, so there is never

a question about which report to use for a certain job. Combining

this information with the candidate’s experience provides the

recruiter with a solid picture of what to expect in the interview.

DATA now prepares behavioral event-based interview questions

that automatically target the weaknesses of each specific

candidate. This feature both standardizes a major part of the

interview process and ensures that the key questions are being

asked.

Traditional assessment reports are sometimes given to the

manager of the new employee or may be discussed with them if

the report requires specialized knowledge. Most often it ends up

in a file drawer, since the information is usually generalized and

only loosely connected with the job.

The Disruptive Difference… and an Entirely New Value System

Talent Acquisition is only the beginning of how DATA delivers value. The

BestWork DATA system uses that same DATA to deliver a wide range of

talent management and talent development applications. With each entry of

DATA from either new employees or existing ones, the DATA pool becomes

richer and more valuable as an effective operating system for human

resources and true human capital management.

Assessments have traditionally been an event. It may have been a hiring

event. It may have been a team building event. Whatever the event,

whatever the value of the event, it ended. BestWork DATA is agile, meaning

that the cognitive and behavioral DATA continues to support decisions

whenever thinking, learning or behavior is important. It does this with

specialized outputs that can be adapted to any situation.

The value is always growing in every BestWork DATA program.

The capabilities of the BestWork DATA system are part of every application,

whether it is for selection or to be used with existing employees. The

various other applications can easily be added as needed to the

administration site that is created for each client. As almost all BestWork

DATA systems are sold under an unlimited usage annual license, current

employees or job candidates can be added at any time.

DATA provides information that is accessible to everyone, right now.

Creating a world of applications would be a limited offering if they were only

usable by specially trained consultants. DATA’s other major innovation is a

method of translating the DATA into practical language that is easily

understood by anyone. This means that all managers can access

information that will make them better managers. It means that every work

group within an organization can have information that helps them work

more effectively together. It means that every employee and and every

executive can make more accurate decisions and with less risk, almost

immediately. There is no need for cumbersome training programs or

expensive workshops.

With any disruptive innovation of the scale of BestWork DATA, there is a

challenge with the scope of possibilities. The opportunities are abundant

but all do not have to be seized at once. Any DATA application will bring

significant rewards to the user. Other applications can be added as the

need arises. It is a system designed to grow with the client, not overwhelm

them. It is a system designed to make decisions easier, not more complex.

It is a system designed to unlock the potential of the most valuable

resources within any enterprise…its human capital.
