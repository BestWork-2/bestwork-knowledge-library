Cyber Breaches & Vulnerability

The purpose of this document is to unbundle the various elements in the

world of cyber security including the threats and breaches, internal and

external. It also considers the countermeasures that are used to address

these issues and introduces some new ideas.

External Threats

•Computer hardware - flaws in the physical components of a

system that can be exploited by attackers

•Computer software - malicious pieces of computer code and

applications that can damage the computer, as well as steal

personal or financial information

•Security system - a combination of hardware and software that

limits the exposure of a computer or computer network to attack

•Security procedures - consist of steps and tasks that are

necessary to ensure security in an organization's day-to-day

operations

Internal Threats - Intentional

•Fun/Challenge - “See if I can”

•Theft - Intent is to steal something

•Harm - Intent is to harm the enterprise

Internal Threats - Unintentional

•Hard-wired non-compliance - Not following security procedures

consistently because of personality traits

Responses

•Monitoring - Additional monitoring of security points

•Training -Additional training on security protocols

Behavioral DATA response to hard-wired non-compliance with cyber

security protocols - People have hard-wired personality traits. Some of

those traits are counter to cyber security protocols. Identifying these traits

enables the company to positions these individuals in areas that do not

require compliance with the security protocols.

Using a combination of advanced psychometric tools and surveys, work

groups can be analyzed as to security compliance threats and the threat

indexed for management purposes and for adapting security measures

where necessary.

Job Fit for Cyber Security Roles

An individual’s knowledge of cyber security procedures has little to do with

their actual behaviors that can affect the security. To ensure that they have,

not only the knowledge but also the ability to deliver the necessary

procedures consistently, it is necessary to inventory their personality traits

and cognitive abilities.

•25% of the population learns and processes information quickly

enough to understand the ever changing and evolving landscape

of the cyber security world.

•25% of the population can effectively handle the level of details

necessary for many cyber security roles.

•50% of the population makes exceptions to rules and procedures

that are part of the cyber security system.

•25% of the population will not call out a security problem if they

see it.
